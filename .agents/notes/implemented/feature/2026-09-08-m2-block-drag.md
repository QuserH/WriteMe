# Agent Note: M2 块拖拽——自研指针交互与折叠树层级移动

Status: implemented

## Problem

用户要求对齐 Craft 的块操作，并明确要求交互自研。按顶层 DOM 索引定位时，展开的整棵折叠树被视为同一行，子块不能独立拖动；以标题右半区推测拖入，预览在标题下而实际追加到末尾，落点与结果不一致。旧实现混用从 1 开始的块位置、全篇替换与异步删除尾部空段，容易破坏选区或用户保留的空行。

## Decision

- UI 集中于 `src/editor/BlockHandle.tsx`，纯位置和移动事务集中于 `src/editor/blockTree.ts`。保留自研指针交互，不引入第三方 drag-handle 扩展及协作依赖。
- 递归读取文档及展开折叠块的直属内容，用 `view.nodeDOM(pos)` 对应节点，记录 pos / parentPos / index。首块位置为 0，边界由 PM nodeSize 计算，不把 DOM 序号当节点位置。标题不单独拖走，拖动标题行移动整个折叠块。
- 折叠块命中区域为标题行，子项有独立行和手柄；收起子树不参与命中。正文保持约 720px 阅读列，外层留白覆盖手柄移动路径。
- 5px 阈值区分单击菜单与拖动，pointer capture 保持连续；Escape、pointercancel、丢失捕获、窗口失焦和销毁统一取消并清理。文档在拖动期间发生其他修改时取消旧操作，避免使用过期位置。
- 指示线与提交共用 DropTarget。目标标题中部、文本起点右侧表示移入，线位于标题下且插为第一个子块；标题上下缘表示前后排序。向左跨过缩进把目标提升到父块之外，线起点显示最终层级。编辑区之外释放取消操作。
- `moveBlockTransaction` 在一次事务内删除源子树，经 mapping 映射插入点再插入完整节点。只打开目标容器及祖先，保留移动子树自身的 collapsed。禁止移入自己或后代、禁止覆盖标题。拖动后选中整块，键盘缩进保留文本选区，closeHistory 让结构调整一次可撤销。
- schema 允许仅有标题，见 [折叠块笔记](2026-09-09-toggle-block.md)。移走最后一个子块无需补正文，也不异步删除尾部空段。
- 幽灵复用 `.writeme-editor.wm-ghost-editor` 排版，字号与原文一致；保留现有 0.85 不透明度，高度限 300px。源块淡化、目标标题轻量高亮，细落点线附“移入折叠块”提示。
- 边缘滚动作用于真正的 `.editor` 滚动容器，以 requestAnimationFrame 持续推进，指针停止移动仍可滚动。块菜单紧凑竖排，按实际位置操作，并限制在视口内。
- 日常产物遵循 [独立版构建流程](../process/2026-09-08-release-vs-debug-launch.md)，源码、浏览器验证和根目录 WriteME.exe 对应同一次修改，避免用户在旧包上验证。

## Verification

`npm run test:editor` 覆盖首块 pos=0 移入、嵌套子树跨父级、移出最后子项、跨展开子树排序、禁止祖先移入后代、取消、持续边缘滚动、保存与撤销。模型测试枚举三层树的百余种合法移动，逐项验证 schema、文本块（含 marks）、空行和数量保持。浏览器用隔离存储运行，不改用户桌面数据库。

## Alternatives considered

- **复用官方 DragHandle**：原生 DnD 可处理许多选区与位置细节，通用性强；用户已要求自研，当前需要统一控制幽灵、折叠命中与取消行为，因此没有重新引入插件。
- **整篇子节点数组重排**：顶层排序容易理解，正确区间为 `[0, doc.content.size)`；但嵌套需要重建父链，全篇替换丢失精确选区映射。局部删除/插入的一次事务保留 PM 映射与历史能力。
- **不做跨层级移动，仅保留键盘缩进**：成本最低，但不能满足用户明确提出的子块拖入和拖出体验。

## Consequences

- 收益：可见折叠层级具有独立拖动入口，预览层级与位置一致；移动完整子树不丢字、不强制展开自身、不清理用户空行。
- 代价与上限：命中入口为文档与折叠块的直属块；普通列表、引用和代码作为整体移动。列表内部单个 listItem 的独立指针拖拽、多块同时拖动、跨文档拖动尚未实现，扩展时须同时更新合法容器地址规则与回归，不能只加 DOM 命中。
- 原生版幽灵块不透明度设置已实现，见 [设置滑块](2026-09-09-settings-ghost-opacity.md)；Web 基线保留当前样式。
