# Agent Note: 原生编辑导航——左侧标题目录与纸张外工具区

Status: implemented

## Problem

用户要求参照 Craft 的实际界面完善原生版。已有斜杠菜单和选区浮层缺少固定的操作入口；先前把普通折叠标题也列为目录，并把目录放在右侧，混淆了结构编辑与文档导航。用户明确指出目录应在左侧，并授权查看已登录的编辑器。插入与样式转换需要不同语义，不能因为点击面板而替换选中文字、丢失折叠子树，或改变已完成的待办状态。

## Decision

- 参考用户已登录的 Craft 编辑器整页布局、左侧当前文档目录及右侧插入/格式/页面样式/信息面板，以及 [Craft 格式化文档](https://support.craft.do/zh-Hans/write-and-edit/formatting)。实际页面的普通折叠块没有进入目录，空目录提示为“使用标题、页面或卡片创建目录。”。WriteME 的当前文档目录只收录标题，空状态使用“使用标题创建目录。”。M4 的中央文档卡片属于资料库浏览，并不是正文内的嵌套页面/卡片节点。
- `MainWindow` 左栏宽 292px，底部胶囊在空间笔记列表与当前文档目录间切换，默认当前文档模式。`DocumentOutlinePane.cs` 显示文档图标、名称、更新时间和标题目录；空间模式提供空间、文件夹、标签、收藏、最近、全文搜索、每日笔记和卡片总览，详见 [资料库导航](2026-09-10-library-and-search.md)。顶栏高 56px，包含侧栏开关、当前文档名、撤销/重做与文档菜单。标题修改、保存和文档切换同步左侧元信息与顶栏名称。
- `EditorSidebar.cs` 位于纸张外侧，默认收起成 40px 宽的圆角图标胶囊。用户完整展开 Craft 后可见横向「插入/格式/样式/信息」标签与纸张外工具区，因此展开态使用 280px 独立栏，标签与关闭按钮在上方、可滚动内容在下方，不再在纸内叠加面板。四个入口均有实际功能、提示与无障碍属性；重复点击入口或关闭按钮收起。页面/信息的字体、封面、分割线、统计和管理动作见 [M5 页面与资产](2026-09-10-page-assets-and-portability.md)。
- `SidebarGlyph.cs` 使用统一 24×24 坐标的原生矢量图标，线条粗细与端点一致；Aa、标题编号与 B/I/U/S 使用明确字体绘制，前景色跟随按钮状态。样式集中在 `Themes/EditorSidebar.axaml`，包括浅蓝选中、悬停、混合格式与键盘焦点。文字样式按钮及分段按钮显式铺满各自网格并居中，避免 Avalonia 默认对齐使背景只包住文字、图标偏在一边。
- 插入面板使用 34px 高的紧凑单列行，左图标、文字和右侧浅色加号，复用 `BlockCommand.All/Search` 的中文、英文与拼音筛选，提供正文、三级标题、折叠块、列表、待办、引用、代码块、分割线，以及文件与图片选择入口。在当前块之后插入；只有独立的空正文段落复用当前位置，不替换文字选区、折叠标题或已有子树。插入折叠块遵循 [折叠交互](2026-09-09-toggle-block.md)，默认收起。
- `DocumentSession.InsertBlock` 是一次可撤销事务。在有序列表项后插入其他块时拆开列表，保留前后内容和后续编号；分割线后提供可继续输入的正文。所有操作沿用原生文档树、统一历史与自动保存，数据契约见 [原生编辑核心](../architecture/2026-09-09-native-block-editor.md)。
- Aa 面板顶部是 3 列 × 2 行的标题/副标题/小标题/正文/引用/代码样式按钮；下方用 32px 高的分段控件提供五种文字格式、列表/折叠类型、缩进、链接和清除格式。五色高亮与移除按钮使用圆形色块；不常驻显示选区字数或当前块的重复说明。文字格式状态来自 `SelectionFormats`，显示未设置、全部或混合。无文字选区时禁用文字格式，光标在已有链接中仍可编辑该链接。链接复用 [选区工具栏](2026-09-09-text-formatting-toolbar.md) 的地址表单与草稿保护；高亮使用显式设置语义，重复应用不移除。Craft 实际选中文字时也显示浮层，因此两类入口共用命令并保留。
- 分段控件与高亮之间提供共用 `TextColorPicker`：默认及九种预设文字色、自定义十六进制输入、混合提示。颜色状态复用 `SelectionFormats`，命令使用 `SetTextColor`。选择器按会话、Revision 和选区快照缓存，普通焦点/布局刷新不清空草稿；提交再次核对快照和当前面板，旧文档或旧修订的回调失效。自定义输入的 Enter/Escape 保护中文预编辑，内容超过窗口高度时随原面板滚动。
- 块样式作用于光标所在块。选择当前样式不创建空历史或重置任务勾选状态；将一个引用段落改为正文时，前后引用仍保留；有序列表中的一项改为折叠块时，后续编号保持原值。格式转换和插入分别调用核心命令，不能用文本替换模拟结构变化。
- 增加/减少缩进调用已有 `DocumentSession.Indent/Outdent`。只有前一个同级块可接收内容时允许增加折叠层级，只有折叠子项可减少层级；完整节点、后代和收起状态保留，焦点回到正文，操作沿用统一撤销历史。
- `DocumentOutline.Read` 遍历支持的容器，只收录 `heading`，包括收起父级内部的真正标题。普通折叠标题、正文和未知原子块不进入目录。目录层次使用标题等级栈；折叠容器深度不额外增加目录缩进，跳级标题不产生空层。标题改为正文后移出目录，撤销恢复。列表使用虚拟化 ListBox，只生成视口内控件；文档树未变的光标移动复用条目集合。
- 点击目录条目或在列表中按 Enter 调用 `DocumentSession.Reveal`：只展开目标标题必要的折叠祖先，再定位光标并滚动，其他分支状态保留。获取焦点、方向键选择或刷新选中项均不执行跳转，避免打开目录就改变折叠状态。必要的展开共用一次历史；纯跳转不增加历史。全文展开/收起放在文档菜单，仍只处理有子内容的折叠块，不为叶节点添加内容，空操作不增加历史。
- 面板操作前检查当前会话、编辑表面与模型长度及中文预编辑状态；文档切换期间禁用编辑命令。目录核对缓存文档树与会话，旧条目无法定位新会话。搜索框中文候选确认 Enter 不执行插入，预编辑 Escape 不关闭右侧面板。
- `Ctrl+Alt+1/2` 打开右侧插入/格式并进入面板焦点，Escape 关闭并回到正文。`Ctrl+Alt+3` 打开左侧当前文档目录，在 UI Dispatcher 的 Input 阶段核对可见性与会话后聚焦；Escape 从目录回到正文。`Ctrl+F` 切到空间模式并聚焦全文搜索。正文 Tab/Shift+Tab 继续处理折叠层级；面板保留原生 Tab 与焦点提示，不抢占 `Alt+F10` 浮层入口。
- `MainWindow` 采用实际 Craft 页面计算样式对应的 `#FCFDFE` 应用底色、26px 圆角白色纸张、细边线与多层低透明度阴影，纸张上沿位于顶栏下方。文档标题为 32px 半粗体，下方是细分隔线，更新时间放在左栏；底部状态与纸张圆角之间保留留白。`DocumentRegion` 为收起/展开工具区分别让出 72/312px，纸张本身随可用区域调整。内容区窄于 680px 时减少左留白，保留可编辑宽度。浅色、深色和自定义页面分别绘制清晰边线，禁用格式按钮使用淡化状态。
- 实际检查 Craft 的 `/` 根菜单、列表和表格二级菜单，以及 Enter/方向键行为。原生斜杠菜单使用 232px 宽度、32px 行高、13px 中等字重、10px 行圆角和 18px 外圆角；浅灰表面、轻灰悬停与分层阴影集中在 `Themes/EditorMenus.axaml` / `Ui.FloatingShadow`。选区浮层与链接补全共用表面和阴影，普通按钮去掉偏黄的灰底。颜色资源注册和深色映射同步维护；本机菜单使用实色表面，没有复现网页背景模糊。分类、搜索、焦点和原子执行规则见 [原生编辑器](../architecture/2026-09-09-native-block-editor.md)。
- 表格和分栏插入、当前区域的文字格式/颜色/段落对齐都由 `ActiveEditor` 解析目标。布局缓存更新不能清掉选区草稿，中文候选时禁用结构命令。原子块的插入、共享历史、紧凑区域坐标与内部导航见 [原生表格与分栏](2026-09-11-native-tables-columns-and-editing.md)。
- 窗口宽度小于 1080px 且右面板打开时，暂时隐藏左栏，关闭右面板后恢复左栏模式及显示偏好。窄窗口切回左栏或使用 `Ctrl+Alt+3` 会关闭右面板；左右面板不同时压缩正文到不可编辑的宽度。

## Verification

- `DocumentToolsTests` 覆盖收起折叠块后插入、复用空段落、保留选区与子树、列表拆分及编号、任务样式幂等、单段取消引用、隐藏标题导航、展开全部的空操作历史，以及普通折叠项排除、标题等级组织、标题转换/撤销的目录更新。
- `CraftInteractionTests` 通过 Avalonia headless 的真实指针和键盘事件验证搜索插入、面板切换、格式混合状态、链接表单、单步撤销、中文预编辑、左侧远处隐藏标题跳转与文档切换；缩进按钮的回归确认子折叠块及正文整体移入/移出，保留右箭头并可依次撤销。`TextColorTests` 另覆盖双入口颜色/默认恢复/自定义值、IME 与旧文档草稿保护、窄窗口及关闭后的颜色保存。`LayoutWorkspaceTests` 核对 1493px 全展开布局的纸张与工具区不重叠，并渲染深色、窄窗口与实际复合内容；完整原生测试共 208 项通过。
- 10,000 项大纲测试确认只有视口附近 ListBoxItem 被实例化，光标移动复用条目，并可定位末尾标题；这是虚拟化正确性测试，不是完整性能基准。
- 隔离 SQLite 的 MainWindow 测试核对左右位置、左栏模式、获取焦点不跳转，以及关闭后的文字格式、父子折叠状态与原文保存；820px 窗口验证正文宽度、左侧目录快捷键与模式恢复，820×560 窗口确认可滚动到插入面板最后一项。`WRITEME_QA_ARTIFACTS` 指定原生渲染图输出目录，包含收起状态、插入、格式、左侧目录和窄窗口；逐图检查网格对齐、按钮密度和滚动边界，不操作用户窗口或真实资料库。

## Alternatives considered

- **不增加面板，复用斜杠菜单和浮层**：界面占用最少，原有命令已经覆盖大部分块和文字格式；但它缺少用户明确要求的固定工具入口，也无法提供隐藏标题的导航，因此保留这些快捷入口并补充右侧面板。
- **让侧栏完全替代选区浮层**：格式入口唯一、焦点管理简单，适合始终保留大面板的工作方式；选区附近的快速格式操作仍有价值，且窄窗口需要随时关闭面板，因此两种入口复用相同核心状态和命令。
- **始终使用纸内圆角浮层和纵向图标**：短暂操作时占用少，也保留既有实现；但用户完整展开后的参考是纸张外独立栏，纸内大量右留白会让正文显得偏斜。保留收起胶囊，展开时切到横向标签与独立工具区。
- **工具面板直接覆盖正文，不预留空间**：正文不重新排版，适合暂时查看信息；插入、格式和定位是持续写作操作，遮住当前编辑位置会干扰观察结果。因此让整个纸张避开工具区，窄窗口暂时让出左栏。
- **继续凭截图估计颜色和圆角**：不用读取页面结构，粗略布局较快；用户指出整体只有轮廓接近，菜单分类也没有核对。对已授权参考做真实键盘/鼠标交互与计算样式读取，取可复用的尺寸与层次；仍使用原生控件，避免为了模糊材质引入浏览器或改变编辑核心。
- **按可见投影生成大纲**：实现更简单、条目更少；收起祖先后无法找到内部标题，会使导航依赖手动展开。使用完整文档树生成条目并按需展开路径，保留原有折叠状态。
- **把标题与折叠树合并到右侧大纲**：可用一个入口浏览全部层级，也便于放置全文折叠命令；但普通折叠只是内容容器，不代表章节，合并后大量条目淹没标题，且违背实际 Craft 的左右分工。当前文档导航放回左侧，只收录标题；折叠命令保留在编辑器与文档菜单。

## Consequences

- 收益：左侧章节导航与右侧编辑操作职责明确，普通折叠不再挤占目录；独立纸张、横向工具标签、统一图标和紧凑面板与完整参考一致。文字格式与结构操作共享历史，隐藏标题可定位，折叠子树和旧数据契约保持完整。
- 代价与上限：右侧展开宽度为 280px，纸张区域让出 312px；需要维护收起/展开两种表现、左右响应规则、原生图标、条目缓存、颜色草稿与嵌套焦点。目录模式启用时，文档树变化仍会重建完整条目集合。正文内的嵌套页面/卡片导航和任意高亮取色尚未提供，不能把布局调整解读为完整或像素级复刻。
