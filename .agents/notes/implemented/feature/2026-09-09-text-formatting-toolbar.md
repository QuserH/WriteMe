# Agent Note: 选区格式工具栏——内联标记、链接草稿与焦点保留

Status: implemented

## Problem

用户要求延续 Craft 的编辑体验。已有快捷键能改变部分文字样式，但没有可发现的选区工具栏。链接输入需要临时把焦点移到表单，不能因此丢掉原选区、写到错误位置，或让中文候选确认意外提交。工具栏也不能抢占折叠块原有的 Tab 缩进。

M3 继续补充文字颜色：选区需要同时保留粗体、链接和高亮，恢复默认色也不能删除导入文档的字体等其他样式。浮层与右栏应显示相同颜色状态，自定义输入必须保留草稿并遵循相同的选区和输入法边界。

## Decision

### Web 基线

- 参考 [Craft 格式化文档](https://support.craft.do/zh-Hans/write-and-edit/formatting)，由 `src/editor/FormattingToolbar.tsx` 实现紧凑白色浮层、线性 SVG 图标、按下状态、五色高亮面板与链接表单。编辑器宿主只负责扩展装配；交互不引入第三方浮动菜单插件。
- 粗体、斜体、下划线、删除线、行内代码与链接复用 StarterKit 的 marks；高亮使用官方 Highlight 的 multicolor 模式，`attrs.color` 随现有 JSON 保存。数据契约见 [M1 笔记](2026-09-08-m1-tiptap-block-editor.md)。清除格式只移除 marks，不改变标题、列表或折叠树。
- 仅在可编辑的非空 TextSelection 含文字时显示，整块选择与代码块不展示。订阅编辑器事务、焦点、鼠标选区结束及滚动，使用 requestAnimationFrame 合并重定位；拖选与 composition 期间隐藏。窗口失焦、选区消失或文档切换会清理浮层。
- 普通按钮 mousedown 保留浏览器选区，命令按当前 PM 选区执行。链接与高亮面板记录目标范围；提交前重新核对范围，文档变化会取消旧草稿，避免使用过期位置。每次格式命令使用 closeHistory，支持独立撤销。
- Ctrl+K 打开链接表单；光标位于已有链接时先扩展到该链接文字。无协议地址补 https，仅接受有效的 http / https / mailto / tel 地址。无效地址显示就地错误；Esc、外部点击和切换文档放弃草稿。输入法确认 Enter 不提交。编辑状态的普通链接点击不跳离文档。
- 高亮提供黄色、绿色、蓝色、粉色、紫色预设及移除；混合选区可移除其中已有的高亮或链接，不要求整段都具有相同 mark。
- Alt+F10 将焦点移入工具栏，左右/Home/End 导航，按钮提供中文标签、快捷键提示和 aria-pressed。Tab/Shift+Tab 留给原有折叠与列表缩进；Esc 关闭后，在新选区上可以重新打开。
- `floatingPosition.ts` 与斜杠菜单共用实际 `.editor` 边界计算，优先放在选区上方，空间不足时换边；跨屏选区没有外侧空位时落在可见编辑区内。完全滚出视野的选区隐藏工具栏。拖动手柄忽略浮层区域，监听器与尺寸观察器随实例释放。

### C# 原生版

- 选区浮层提供评论入口，`Ctrl+Alt+M` 使用同一文字批注捕获规则；无选区时进入段落评论。评论标记属于结构关联，清除文字格式必须保留 `comment` marks，显式输入样式不能扩展或复活已删除的批注。原文关联、草稿与逐条回复见 [原生评论](2026-09-11-native-comments.md)。

- `native/WriteMe.Desktop/Editing/FormattingToolbar.cs` 在原生编辑视口内绘制 14px 圆角浅灰浮层，表面与分层阴影共用原生菜单主题，替换正文上方的常驻工具栏。选中文字后显示，拖选、块拖动、中文预编辑、代码/未知块选区、光标折叠、视口外选区与外部焦点时隐藏。普通折叠三角与此前的悬停手柄规则保持独立。
- `SelectionFormats` 从 C# 文档投影读取选中文字的真实 marks，粗体、斜体、下划线、删除线和代码按钮用原生 ToggleButton 表示未设置、全部设置或混合状态，并提供中文无障碍说明。`TextColorCoverage` 与 `UniformTextColor` 单独读取颜色，不因 textStyle 的其他属性不同而误判同色选区；不同颜色或部分着色显示混合。高亮提供五个色块及移除；清除格式只影响选中文字，不改变层级或隐藏子树。
- 浮层保存文档会话、修订号、选区方向和文字范围。普通格式操作保持选区并进入统一历史；链接、高亮和块转换面板的回调还核对打开时的目标快照，旧草稿即使延迟回调也不能作用于另一篇笔记或新的选区。文档修改或切换会放弃草稿。
- Ctrl+K 在浮层内打开链接表单。光标位于链接时跨相邻、具有相同 link 属性的文字 run 扩展，粗体/斜体分段不会截断链接；不同链接、无链接文字和段落边界停止扩展。已有链接预填地址，修改保留已有 link 属性，支持移除、取消与就地错误提示。原生 TextPresenter 的 PreeditText 非空时，确认候选的 Enter/Escape 不提交或关闭表单。
- 链接和高亮的“应用”使用显式设置，重复应用相同值不会切换为移除或增加空撤销记录；普通粗体等继续使用开关语义。软换行不参与“全部文字已设置”的判断，保持状态显示与实际切换一致。渲染器组合下划线和删除线，代码字体保留同时设置的粗体/斜体。
- Alt+F10 从正文选区进入工具栏，左右/Home/End 导航，Enter/Space 操作，Tab 在浮层控件内循环，Esc 关闭并回到正文。正文获得焦点时，Tab/Shift+Tab 仍归折叠层级处理。鼠标操作后返回正文，键盘连续设置格式时保留工具栏焦点。
- 选区几何取自 AvaloniaEdit 的可见文字矩形，按原生编辑区域约束宽度和上下位置，窄视口允许按钮换行，跨屏选区落在可见范围内。选择变化、滚动、布局与焦点通知合并到 UI Dispatcher；格式提交临时使文字布局失效时，等待 VisualLinesChanged 更新位置，不先隐藏带有键盘焦点的工具栏。监听已处理的焦点事件，确保从其他输入框返回正文时重新显示。
- 核心仍使用 TipTap JSON、`DocumentSession` 的统一撤销及原生自动保存。模型、快捷键和保存边界见 [原生块编辑器](../architecture/2026-09-09-native-block-editor.md)。UI 验证使用 headless 原生控件和隔离 SQLite，不操作用户桌面或真实笔记。
- [右侧 Aa 样式面板](2026-09-09-editor-sidebar.md) 提供固定的文字/块样式入口，复用 `SelectionFormats`、公共高亮配色与本文的链接表单。打开侧栏时隐藏当前浮层，文字格式操作后返回正文可再次显示选区浮层；两者使用同一套文档格式事实和撤销历史。

### 原生文字颜色

- `TextColor.cs` 将文字颜色写入 TipTap 标准 `textStyle` mark 的 `attrs.color`。接受带或不带 `#` 的 3 位/6 位十六进制，规范为 `#RRGGBB`；非法输入不改变模型或历史。`NoteJson` 已保留未知 marks/attrs，无需改库或迁移正文。
- `DocumentSession.SetTextColor` 只修改选区内的可格式化可见文字，跳过代码和未知原子块，保留隐藏子树、其他 marks 和 textStyle 的其他属性及 Extra。恢复默认只移除 color 属性，没有其他属性才删除空 textStyle；重复设置同色不产生历史，整次跨块设置可一次撤销。显式文字色在渲染时优先于链接默认色，恢复默认后仍保留链接本身及默认样式，高亮可同时存在。
- 共用 `TextColorPicker.cs` 采用 5 列 × 2 行的圆形 A 色样：默认及灰、红、橙、黄、绿、青、蓝、紫、粉九色，配色集中在 `Ui.TextColors`。这些颜色沿既有界面配色选取，并非从 Craft 逐色测量。自定义输入和“应用”位于色样下方，错误就地提示；恢复默认用单独色样，不把空输入误当清除操作。
- 浮层复用现有 A 按钮打开“文字颜色与高亮”，上方为文字颜色，下方为既有五色高亮；图标文字跟随当前文字色，底线跟随高亮。面板在编辑区高度内滚动，不增加一排常驻按钮。右侧 Aa 使用同一选择器，目标会话、修订号或选区变化才重建，普通刷新保留正在输入的草稿；提交时重新核对目标。
- Enter 应用合法自定义色，Escape 放弃草稿并回正文。浮层父级和选择器都检查 TextPresenter 的 PreeditText，中文候选确认的 Enter/Escape 不会提交颜色或关闭面板。切换文档、修订或选区后，旧回调不能继续设置颜色。UI 仅对非空、可格式化选区开放；核心仍支持无选区的 TypingMarks，为后续输入继承留在同一事务模型中。

## Verification

- Web 的 `npm run test:editor` 包括精确文字范围、连续样式与单步撤销、混合 mark 清除、折叠标题高亮刷新、链接验证/取消/更新/移除、Alt+F10 与 Tab 缩进并存、跨段和跨屏选区、窄窗口和滚动隐藏。保存断言等待 800ms 自动保存完成；浏览器 Selection 测试等待 selectionchange 进入 PM。
- 原生 `npm run native:test` 共 208 项通过，其中 `FormattingTests.cs` 的 19 项覆盖格式混合状态、跨软换行切换、重复应用幂等、实际指针点击的精确范围、跨 marks 链接预填与更新/撤销、链接地址验证与中文预编辑、草稿跨修订/文档失效、键盘连续操作、外部焦点、拖选隐藏、窄视口与真实滚轮事件、组合文字渲染和窗口关闭后的 SQLite 保存。侧栏复用与切换覆盖在 `CraftInteractionTests.cs`；`NativeEditorTests.cs` 另验证缩进续行的选区矩形、粗体高亮、中文预编辑和点击坐标。
- `TextColorTests.cs` 的 6 项覆盖精确范围、重复同色无历史、默认恢复保留其他 textStyle 属性、JSON 往返、中文/emoji/软换行、隐藏子树和代码保留，以及浮层/右栏双入口的真实文字 run 色值、非法输入、预编辑、旧文档草稿失效和撤销。隔离 SQLite 的窗口测试同时验证文字色与空待办退出在关闭后保存；820×560 窗口检查颜色面板与自定义输入可用。`artifacts/native-m3-qa/` 的正常侧栏、窄窗口和浮层 PNG 已逐图检查。
- `NativeWindowSavesFloatingToolbarFormattingAndRendersTheCompactPanels` 在隔离库中通过窗口和控件操作保存粗体/高亮/链接，并重新读库核对正文与折叠树。设置 `WRITEME_QA_ARTIFACTS` 可输出原生 headless 渲染的工具栏、高亮和链接面板 PNG，用于视觉检查；此验证不等同于实际系统 IME 或其他平台验收。

## Alternatives considered

- **复用 BubbleMenu 与通用定位库**：支持大量通用定位边界，减少维护负担；当前用户选择自研交互，工具栏需要与折叠、块手柄、草稿选区及现有菜单统一边界，因此保留轻量组件，复用编辑引擎的命令与官方 mark 扩展。
- **让常驻侧边格式面板完全替代浮层**：目标稳定、容纳选项多，适合复杂块与页面样式；常用文字操作在选区附近仍更直接，也节省窄窗口空间。当前右侧面板作为补充入口存在，保留可独立使用的选区浮层。
- **不做工具栏，仅保留快捷键**：没有浮层与焦点维护成本，但格式能力难发现，无法满足用户要求的可视化编辑体验。
- **原生 Popup/独立链接对话框**：平台窗口管理和自动放置可减少部分定位代码，容纳复杂表单也容易；本次工具栏只服务当前文字选区，使用编辑区内的 Avalonia 控件可以统一焦点、视口限制和草稿生命周期，避免为简单链接输入切换独立窗口。
- **另建 color mark 或复用 highlight.color**：单独标记便于直接开关，复用高亮字段则无需增加数据入口；前者偏离已有 TipTap 文本样式契约，后者无法让文字色与背景高亮共存。采用 textStyle.color，移除时保留同一 mark 的其他属性，代价是需单独处理属性合并和颜色混合状态。
- **本步只做预设色，或加入完整取色器**：预设色实现最小、视觉一致；完整色盘则适合反复微调。当前预设覆盖快速操作，十六进制输入覆盖指定颜色，并复用已有表单的草稿和 IME 保护；渐变色盘、透明度与任意高亮色仍留待后续明确需求。

## Consequences

- 收益：文字格式、嵌套标题与已有保存机制贯通；输入链接不会改变作用范围，快捷键缩进与浮层键盘入口分离。
- 代价与上限：Web 需要维护 PM 选区与 DOM 焦点，原生需要维护文档快照、颜色属性合并与 Avalonia 文字布局/焦点。原生文字色支持不透明十六进制值，高亮仍为五种预设，尚无任意高亮取色；整页默认色、背景和字体由 [页面样式](2026-09-10-page-assets-and-portability.md) 管理；Web 基线暂未提供新增文字颜色入口。浮层针对文字选区，不是多块结构选择。原生基础块样式侧栏见链接笔记，新增 mark 应同步渲染、数据说明和保存回归。
- 两版实现分别复用各自的文字设施，共享交互约定和数据契约；原生工具栏通过 Windows 上的 headless 测试及渲染检查，实际系统输入法、缩放和其他平台仍需人工验收。完整原生产品迁移边界继续由原生架构笔记约束。
