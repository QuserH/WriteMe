# Agent Note: M2 斜杠菜单——搜索范围、键盘导航与块转换

Status: implemented

## Problem

用户以 Craft 为参照，要求斜杠菜单支持输入搜索词、方向键选择、Enter 应用，并能在折叠子树中转换内容。搜索不能只删除最后一个字符或吞掉光标后的原正文；菜单不能因滚动脱离光标，也不能让输入法确认候选的 Enter 意外执行转换。

## Decision

- `SlashMenu.tsx` 独立管理搜索会话。非代码文本块中，光标前匹配块首 `/` 加至多 48 个搜索字符时，记录实际 PM from/to/query；正文中部的斜杠、重复斜杠和非空选区不触发。以触发位置定位，后方正文属于原内容，不属于搜索范围。
- `blockCommands.ts` 统一块类型、中文名称、说明、英文与拼音关键词及转换命令。支持正文、标题 1–3、项目符号、编号、待办、引用、代码和折叠块；查询经 NFKC、大小写和空白归一后按词过滤。搜索变化重置高亮，相同查询滚动保持选择。
- 上下键在过滤结果内循环，Enter 应用；无结果显示空态并允许普通 Enter 换行。Esc/外部点击/失焦关闭并保留已输入文字，同一已关闭触发位置继续输入不强制重开。composition、isComposing 与 229 键码期间不消费候选确认；按键仅作用于当前编辑器。
- 执行前重新验证完整范围，同一 closeHistory 命令链删除 `/关键词` 并转换，支持一次撤销。正文转折叠保留 marks；折叠标题转常规块先解包并保留子内容。选择当前已有的标题、列表或引用类型不意外取消该类型。折叠行为见 [折叠块笔记](2026-09-09-toggle-block.md)。
- 使用统一 SVG 图标、结果计数与键盘提示；listbox/option、aria-selected 及编辑区 aria-activedescendant 关联当前项。鼠标按下菜单保留编辑选区。
- `floatingPosition.ts` 约束编辑区和窗口边界，底部光标使用 bottom 向上定位，滚动与缩放后重定位，光标完全移出视野时隐藏。高亮只调整结果列表自身 scrollTop，不调用 scrollIntoView 带动正文；菜单内部滚动不重置高亮。

## Verification

`npm run test:editor` 覆盖中文和英文过滤、查询修改后的高亮重置、上下循环、原文后缀与 marks 保留、同类型转换、无结果与 Esc、中文 composition、窄窗口底部定位、菜单滚动不带动正文以及一次撤销。

## Alternatives considered

- **复用现成扩展**：过滤、定位和可访问性通常更全面；但用户已确定自研交互，当前十项菜单可以与块手柄共享命令定义，保持折叠与选区行为一致。
- **不改、只以单个斜杠打开列表**：代码更少，但菜单项增长后查找效率下降，也不符合已查看的 Craft 搜索用法。
- **使用独立搜索输入框**：查询独立于正文，容易加入预览；代价是每次唤起都转移焦点，并需额外恢复中文编辑位置。当前直接在 `/` 后输入，选择时只删除验证过的触发范围。

## Consequences

- 收益：中英文关键词、鼠标与键盘共享转换逻辑，搜索不吞原正文；菜单支持折叠内部和窄窗口，输入法确认不触发转换。
- 代价与上限：触发仍限块首，未实现 Craft 的任意文本位置插入、分级子菜单与内容预览。新增类型需要同步统一命令定义、序列化与回归，不能只增加按钮。
