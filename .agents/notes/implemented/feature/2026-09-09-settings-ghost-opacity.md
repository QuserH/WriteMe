# Agent Note: 设置项——可调的原生拖动幽灵块不透明度

Status: implemented

## Problem

用户觉得反复调整默认幽灵块透明度的差别不明显，要求通过设置自行调节，避免每次编译和重启。原生版还需要让设置确实作用于跟随指针的预览，而不只是修改一个未使用的数值。

## Decision

- `MainWindow.Appearance.cs` 的设置窗口提供 40–100%、步进 5% 的“幽灵块不透明度”滑块，默认 85%。滑动即时更新旁边的预览及 `BlockEditor.GhostOpacity`。
- `BlockEditor` 使用原生 Border 承载 `BlockDragPreview`。跨过拖动阈值后，只创建一次独立的只读原生编辑表面，后续指针移动只更新位置；折叠块展开时预览全部可见后代，收起时只有标题，隐藏孙级不进入投影。字体、富文本、标记、换行宽度、页面底色、表格/分栏与单元格行高沿用原排版。
- 预览宽度取原块可用宽度，高度取实际原生可见行。超过视口的长子树使用已有行高缓存/估算保持外框高度，只在有限视口装配控件，不创建巨幅位图或一万个子控件。抓取点跟随指针，嵌套区域的预览挂到根编辑浮层，不能被单格高度裁掉。
- 不透明度只作用于预览，不作用于正文或落点线。释放、Escape、捕获丢失、模型变化和卸载时隐藏并释放只读会话；嵌套编辑器卸载期间延后把浮层移回原所有者，避免改变正在遍历的祖先子集合。键盘优先级和落点事务见 [原生编辑器](../architecture/2026-09-09-native-block-editor.md)。
- 数值由 `AppPreferences` 写入当前资料库的本机 `library_state`，启动时恢复。偏好不进入正文历史，不同步到其他设备，也不包含在资料库 ZIP 中。主题设置共用这套本机偏好机制，见 [页面与资料可携带性](2026-09-10-page-assets-and-portability.md)。

## Verification

- `KnowledgeLibraryTests.cs` 验证偏好重开恢复；`WorkspaceInteractionTests.cs` 实际拖动原生块，检查幽灵块显隐与滑块数值生效，保存 `drag-ghost-opacity.png` 供渲染检查。
- `BlockDragInteractionTests.cs` 的 8 项覆盖三级退出一层、展开/收起的实际尺寸、长中文粗体的相同断行、隐藏后代、表格/分栏行高、区域内 Escape、关闭时清理及 10,000 子块的有限视口；这不是长文档延迟基准。渲染图在 `artifacts/native/qa-craft-menus-drag/`。
- `npm run native:test` 全套 208 项通过。

## Alternatives considered

- **不做设置，继续调整默认值出包**：没有设置界面和持久化成本；但无法适应主观偏好，也重复用户已经指出的重启成本。
- **只复用 CSS 变量或配置文件**：Web 基线容易接入且便于开发者调整；当前主路线是原生编辑，用户也明确需要可操作的滑块，因此设置连接原生预览和本机偏好。
- **继续复用一行标题卡片**：创建与跟随成本最低；但展开后拖动的是整个子树，一行预览无法表达内容量和实际尺寸。保留单次创建，改为复用现有原生只读排版。
- **直接逐行绘制已有 TextLine 或截取整个编辑区**：可以减少第二个编辑表面，屏幕截图也能忠实保留已显示像素；前者的验证出现重叠字形，后者会包含邻块、裁掉视口外内容，也无法独立保持嵌入布局。独立只读表面使用同一排版管线，代价是拖动开始时生成一次投影与有限视口控件。

## Consequences

- 收益：用户可以立即比较和保存视觉偏好，数值与真实拖动预览一致。
- 代价与上限：需要维护原生预览、设置预览与持久化三处状态，以及预览的释放和区域浮层归属；范围固定为 40–100%。支持一个所选块的完整可见子树，不支持任意多选块、跨区域或跨文档拖动；极长子树的屏外尾部高度仍为缓存/估算。旧 Web 基线继续沿用既有拖动样式。
