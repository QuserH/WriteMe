# WriteME ✍️

一款受 Craft 启发的中文笔记应用。离线优先、本地 SQLite 存储，Windows 桌面优先，支持自建 Docker 服务器同步。

当前主开发路线是 **C# / .NET 10 + Avalonia 原生版**，核心编辑不使用 WebView。块编辑、表格与分栏、段落对齐、标签与双链、空间与文件夹、全文搜索、文档卡片、页面外观、附件、备份、每日笔记、演示与离线同步已接通。原生回归共 **180 项通过**；这仍不代表完整 Craft 功能或跨平台验收完成。选择理由与边界见 [原生块编辑器决策](.agents/notes/implemented/architecture/2026-09-09-native-block-editor.md)。

**试用原生版**：执行 `npm run native:app` 启动最近成功发布的版本，也可直接运行发布目录内的 `WriteME.Native.exe`（默认目录为 `artifacts/native/win-x64/`）。分发时保留整个发布目录；程序运行不需要 WebView2、Node 或另装 .NET。根目录的 `WriteME.exe` 仍是保留的 Tauri 版。

## 工程规范（AI 协作）

- `AGENTS.md` — 接手 AI 必读：代码地图、命令、铁律、环境坑（开发规范以此为准）。
- `.agents/notes/` — 工程决策笔记（为什么改、放弃了什么），与代码同批更新。
- 非平凡改动后运行 `npm run verify-notes` 校验笔记格式；`npm run init-board` 可生成决策看板。

## 原生技术栈

| 层 | 选型 |
|---|---|
| 语言与运行时 | C# / .NET 10 |
| 桌面界面 | Avalonia，本机绘制 |
| 文字设施 | AvaloniaEdit，文字输入、排版、选区与视口虚拟化 |
| 编辑核心 | C# 不可变文档树、富文本范围、折叠与移动事务、统一撤销 |
| 本地存储 | SQLite（Microsoft.Data.Sqlite），兼容既有 TipTap JSON |
| 同步 | ASP.NET Core + SQLite + Docker，版本向量与并发文档版本保留 |

原生版不加载浏览器引擎，但并非全部使用 Windows 系统控件；C# 仍使用托管运行时。已有 10,000 块的视口与隐藏投影正确性测试，尚无同负载长文档性能基准，不承诺未经测量的内存下降比例。

`src/` 与 `src-tauri/` 保留 React 19 / TypeScript / TipTap / Tauri 2 基线。工程校验工具和决策看板模板位于 `.agents/skills/`，不参与应用运行。

## 使用与开发原生版

### 构建与运行

源码构建需要 **.NET 10 SDK**。Node 仅用于下列 npm 命令入口和仓库校验；发布后的程序不依赖 Node。

首次取得源码后，先还原依赖：

```sh
git clone https://github.com/QuserH/WriteMe.git
cd WriteMe
npm ci
dotnet restore native/WriteMe.slnx --locked-mode
```

GitHub 仓库只包含源码、必要图标、测试、工程配置和文档。Node/.NET/Rust/Python 环境、依赖下载目录、`bin/obj/target`、发布目录、测试产物、个人笔记数据库及账号配置不上传；这些文件仍可保留在本机。`package-lock.json`、`Cargo.lock`、`packages.lock.json` 是重建依赖所需的版本清单，随源码保留；Windows 发布另用 `packages.win-x64.lock.json`，不会改写开发锁。同步配置从 `sync/.env.example` 复制，真实 `.env` 不入库。

```sh
npm run native:dev        # 开发运行
npm run native:build      # Release 编译整个原生解决方案
npm run native:test       # 模型、SQLite 与 Avalonia 原生指针/键盘测试
npm run native:release    # 自带运行时的 Windows 发布目录
npm run native:app        # 启动最近成功发布的原生版
```

也可直接执行 `dotnet run --project native/WriteMe.Desktop/WriteMe.Desktop.csproj`。发布命令不会替换根目录旧 `WriteME.exe`，不要只复制原生 exe 而丢掉同目录依赖。

旧程序仍在运行时，可用 `npm run native:release -- -OutputDirectory artifacts/native/craft-layout-win-x64` 发布到另一目录。成功发布会更新 `artifacts/native/latest.json`；关闭旧窗口后再运行 `npm run native:app`，即可使用新版。发布脚本不会关闭或控制当前窗口。

已验证的本机发布目录为 `artifacts/native/craft-layout-win-x64/`，不随源码上传。新克隆仓库需先运行 `npm run native:release`，再启动生成的程序。

### 笔记数据

- 原生版：`%APPDATA%\com.writeme.native\writeme.db`。
- 图片与文件副本在同目录的 `assets/` 中。完整迁移优先使用资料库 ZIP 备份；不要只搬走数据库而遗漏附件。
- 首次启动且原生库不存在时，自动通过 SQLite 在线备份导入旧桌面库 `%APPDATA%\com.writeme.desktop\writeme.db`，校验后使用副本；旧库保留。
- 后续两套资料库各自保存，没有双向同步。浏览器 localStorage 演示数据不会自动导入。
- `WriteME.Native.exe --data-dir "D:\WriteME-test"` 可使用隔离资料库，该模式不自动导入旧库。
- 编辑后 650ms 自动保存；切换笔记与关闭窗口会等待保存。Ctrl+S 可立即保存，更多菜单可导出笔记 JSON。

### 折叠块与块操作

- 输入 `+` 后按空格，或在 `/` 菜单选择「折叠块」；`Ctrl+Shift+7` 也可转换当前块。新建时默认收起，显示右箭头 `▸`。
- 标题中按 Enter 进入新建的子折叠项，父级变成下箭头 `▾` 并显示左侧层级线，子项仍为右箭头。空标题也可以直接回车进入内部；`Ctrl+Enter` 新建同级，Tab / Shift+Tab 增加或减少层级。
- 点击标题左侧的三角展开/收起；矢量箭头、28px 标记列与层级缩进按实际 Craft 参考调整，长标题续行与首行文字对齐。点击尚无子项的三角会创建可编辑内容。各级状态独立保存；`Ctrl+Alt+T` 展开或收起全文折叠块，文档菜单也有明确的全部展开/收起命令。拖走唯一子项后，原父级回到右箭头并移除层级线。
- 只有鼠标悬停的块显示拖动手柄，离开后隐藏。拖动手柄移动整个块及其子树；子折叠块拖出后保留类型、子内容及收起状态。拖到目标标题中间表示移入，向左跨过缩进可移出；落点线显示最终位置，Esc 取消。
- 单击手柄打开块菜单，「取消折叠，保留内容」解除包装。拖动和转换均支持 Ctrl+Z 撤销。
- **删除待办**：悬停到待办行，单击左侧手柄，选择「删除此块」删除整项；复选框与手柄分别响应。只想取消待办格式时，在文字开头按 Backspace，保留文字及子内容；清空文字后，再按 Backspace、Delete 或 Enter 即退出待办回到正文。普通列表也适用，Ctrl+Z 可撤销。
- 当前原生版支持文档与折叠块之间的结构移动；普通列表项的独立指针拖动尚未支持。

### 文字格式与快速搜索

- 在块首输入 `/` 浏览命令，继续输入中文或英文关键词筛选，例如 `/折叠`、`/heading`、`/todo`；上下键选择、Enter 确认、Esc 关闭并保留原文。
- 选中文字后，附近出现浮动格式工具栏，可设置粗体、斜体、下划线、删除线、行内代码、文字颜色、五种高亮颜色和链接；按钮区分全部设置与部分设置。取消选区、拖选或切换焦点后隐藏；清除格式保留块结构。
- 点击浮层的 **A「文字颜色与高亮」**，或右侧 **Aa → 文字颜色**：可选九种预设色，输入 `#426BB3` 或 `#abc` 这样的自定义颜色后按 Enter/「应用」，也可点默认 A 恢复文字色。恢复默认保留粗体、链接和高亮；仅修改所选文字，支持撤销及自动保存。中文候选确认不会误提交颜色。
- `Ctrl+B` / `Ctrl+I` / `Ctrl+U` 设置常用格式，`Ctrl+K` 打开就地链接表单。光标位于已有链接时，自动选中整条链接，包括其中的粗体/斜体文字；支持地址预填、取消、移除与验证。重复应用相同链接或高亮不会将其删除。
- `Alt+F10` 进入浮动工具栏，左右/Home/End 导航，Enter/Space 操作，Esc 回到正文。正文里的 Tab/Shift+Tab 仍用于折叠层级。工具栏左侧的块类型菜单可转换当前块。
- `Ctrl+F` 搜索标题和正文，`Ctrl+N` 新建笔记。文字、格式、折叠与移动共享 `Ctrl+Z` / `Ctrl+Y` 撤销重做。

### 表格、分栏与排版

- **表格**：右侧「插入 → 表格」选择起始行列数，或用 `/表格`。单击格子直接输入；Tab/Shift+Tab 前后切换，最后一格 Tab 自动加一行。表内按钮/菜单支持增删行列、表头、交替行底色及整表删除。
- **选择与粘贴**：Shift+点击或 Shift+方向键选择矩形区域；Delete/Backspace 清空格子并保留网格，直接输入替换选区。复制/剪切/粘贴支持 TSV，包含字段内换行和引号；粘贴自动扩展表格。表格最多 100 行、12 列，超限粘贴不会改动原表。
- **列宽**：拖动列分隔线调整比例，松手生效，Esc 取消；表格菜单可「均分列宽」。显式列宽为 80–1200px，窄窗口可横向滚动。带合并单元格等不支持结构的导入保留原文，并显示提示。
- **分栏**：从插入面板或 `/两栏`、`/三栏` 新建布局，支持等宽、左宽/右宽及拖动分隔线调整比例。减少栏数会把内容并入最后保留栏；「取消分栏」按从左到右的顺序保留全部块。窄窗口自动纵向排列。
- **退出与撤销**：表格内 Esc 先退出文字编辑，再选择整表；Ctrl+Enter 在表格/分栏后继续正文，分栏内 Ctrl+Tab 切换栏。相邻正文段首 Backspace 先选中复合块，再次删除。文字、范围粘贴、行列操作、宽度及结构删除共用撤销重做，并恢复对应区域的光标。
- **排版**：右侧「格式」支持左对齐、居中、右对齐和两端对齐；当前单元格/栏可使用同一套文字色、链接和块样式。页面默认 16px 字号、900px 宽度与 1.35 行距，已有显式外观设置保持原值。
- 简单表格支持 Markdown 表格往返；带列宽/复杂格式的表格与分栏通过 `writeme-json` 围栏保留结构。JSON/ZIP 保留完整数据；跨块富文本剪贴板、合并单元格和公式尚未实现。演示视图目前按阅读顺序展示内部文字，不复现复合布局。

### 左侧导航与右侧工具栏

左侧底部胶囊在「空间」和「当前文档」之间切换。空间模式显示空间、文件夹、全部/最近/收藏、标签、每日笔记与全文搜索；当前文档模式显示名称、更新时间、标题目录、反向链接和链接到的笔记。

- **目录只列标题**：正文中的一级、二级、三级标题进入目录；普通折叠块不会被计入。收起折叠内部的真正标题仍可列出，点击或按 Enter 后展开必要祖先并定位；打开目录、获得焦点或使用方向键选择不会自动展开正文。
- `Ctrl+Alt+3` 打开左侧目录并聚焦，Esc 回到正文；`Ctrl+F` 切到空间模式搜索标题和正文。左上角按钮可隐藏或显示左栏。

纸张右侧的胶囊提供四种工具，展开后在纸张外侧显示「插入 / 格式 / 样式 / 信息」横向标签；页面和工具区各自留出空间，小窗口内的长面板可以滚动。

- **插入**：紧凑的单列块类型列表，支持搜索、表格和分栏。在当前块之后添加，空正文段落可直接复用；保留原来的文字选区和折叠子树。
- **格式（Aa）**：顶部六格切换标题、正文、引用和代码；下方分段按钮设置文字格式、列表、段落对齐和折叠层级。A 色样与自定义输入设置文字颜色，圆形色块设置高亮；选中文字也可设置粗体、斜体、下划线、删除线、行内代码与链接。
- **样式**：选择页面背景、默认文字色、封面、四类字体、字号、行距、宽页和分割线样式；设置按文档保存，并同步到已有表格和分栏。
- **信息**：查看创建/修改时间、位置、字数、区块、附件和估算阅读时间，执行移动、复制、收藏、演示、本地备份恢复及同步操作。
- 点击同一入口或关闭按钮收起面板；`Ctrl+Alt+1/2` 分别打开插入/格式，Esc 回到正文。窄窗口打开右面板时暂时隐藏左栏，关闭后恢复原模式；此时按 `Ctrl+Alt+3` 会切回左侧目录。

### 标签、链接与资料库

- 在正文输入 `#标签`，可从补全中选择已有标签；左侧标签用于筛选。标签支持中文，不从代码或网址片段中提取。
- 输入 `[[`，或按 `Ctrl+Shift+K`，选择现有笔记或新建并链接。`Ctrl+单击` / `Alt+Enter` 打开；目标改名后链接仍有效，删除的目标显示不可用。左侧当前文档中的反向链接可以定位到收起的来源内容。
- 顶栏星标收藏当前文档。左侧“所有文档 / 最近打开 / 收藏 / 文件夹 / 标签”打开文档总览，可切换卡片与列表并按标题或时间排序；卡片显示真实封面、摘要、更新时间与管理动作。“继续编辑”保留当前会话。
- 空间名称菜单管理空间，文件夹右键管理层级。删除容器保留笔记；删除笔记进入回收站，底部提示可直接「撤销删除」并重新打开，永久删除另行确认。搜索覆盖中文短词、标题、折叠、表格和分栏内正文，打开结果会定位到对应编辑区域。

### 页面、文件、备份与每日笔记

- 右侧插入面板的“图片 / 文件附件”把文件复制到本机资料库，单个文件最多 50 MiB。删除正文引用可以撤销，源文件移动不会使副本失效。
- `Ctrl+,` 或资料库菜单打开设置：浅色、深色、跟随系统；幽灵块不透明度滑块为 40–100%，可立即预览并记住偏好。
- 资料库菜单或 `Ctrl+O` 导入 Markdown、纯文本、JSON 或 WriteME ZIP；导入创建副本，原有笔记保留。文档菜单导出单篇 JSON / Markdown / 纯文本，资料库菜单导出完整 ZIP。
- Markdown 导出附带相邻 `assets/`，移动时一起携带；导入能恢复本机图片、附件和自定义折叠内资产。部分文字样式及页面元信息不属于标准 Markdown。**ZIP 备份**包含空间、文件夹、收藏、回收站、封面、附件和内部链接映射，是完整资料迁移入口；不包含账号凭据、本机设置、同步状态或历史版本。当前导入上限为 10,000 文档、1 GiB 总附件。
- 文档菜单/信息中的“本地备份”保留最多 50 份历史快照，普通编辑最多每五分钟捕获一次，远端替换正文和手动恢复前另留快照；恢复支持撤销。
- 左侧“每日笔记”打开当前空间当天的笔记，设置里可指定日期。单机同一天重复打开复用原文档；多设备同时新建同一天时保留双方内容。
- “演示文档”打开原生只读分页窗口，按一级标题或分割线分页。方向键、PageUp/PageDown、空格翻页，Home/End 到首末页，Esc 退出。

### 自建同步

部署步骤见 [同步服务器指南](sync/README.md)。设置中填写服务器地址、账号和密码，点击“登录并同步此资料库”。支持手动同步及每 30 秒后台交换，断网不影响本机编辑。

同一资料库会与所登录账号合并，包含所有空间和附件；更换账号同样会上传当前资料库。要使用相互隔离的账号，请用不同的 `--data-dir`。Windows 登录令牌使用当前用户 DPAPI 保存，密码不持久化。

同一篇笔记在多设备离线修改后，程序保留并发版本并显示冲突入口。可以先“另存为副本”，再“保留这个版本”继续编辑；不是按最后修改时间直接覆盖，也不提供逐字符实时协同。服务器可读取同步内容，当前没有端到端加密。外部服务器要求 HTTPS；本机回环地址可通过 HTTP 或 SSH 隧道测试。

原生 UI 自动回归使用 Avalonia headless，不控制桌面窗口。可先设置 `WRITEME_QA_ARTIFACTS` 再运行 `npm run native:test`，生成表格、分栏、折叠、卡片、页面、附件和同步面板渲染图。本轮图像位于 `artifacts/native/qa-craft-layout/`。实际系统输入法与显示缩放仍由用户在程序中验收。

发布后的无窗口检查可运行 `WriteME.Native.exe --data-dir <新的空目录> --smoke-test`，成功返回 0 并写出 `smoke-test.json`，验证随包运行时、本机 SQLite、标签和全文检索；省略隔离目录或使用非空目录会被拒绝。该检查不替代 UI 回归。

当前原生版尚未完成完整富文本剪贴板、普通列表项独立拖动、正文嵌套页面/卡片和完整屏幕阅读器接口。Android/macOS/Linux 桌面输入未验收；10,000 块回归只证明虚拟化与投影正确，不是性能基准。

## 保留的 Web / Tauri 基线

### 编辑器与回归

Web 版已有折叠树、自研块拖拽、可搜索斜杠菜单与选区浮动工具栏。浮层提供格式、高亮和链接，`Alt+F10` 进入工具栏，左右键切换按钮；Tab/Shift+Tab 保留块与列表缩进。原生版以 Avalonia 控件实现对应的选区格式交互，两版分别维护回归。

编辑器回归测试（使用独立的浏览器存储）：

```sh
npx playwright install chromium  # 首次安装测试浏览器
npm run test:editor
```

### 环境要求

- Node.js ≥ 20
- Rust（MSVC 工具链）
- Visual Studio 2022：C++ 桌面工具（MSVC + Windows SDK）
- WebView2 运行时（Win10/11 通常自带）

### 运行

**运行旧版基线**：双击根目录的 `WriteME.exe`，或执行 `npm run app`。
若还没有这个文件，先执行一次 `npm run release` 生成（前端打包 + release 编译 + 复制）。
之后改了代码想刷新日常版本，随时再跑 `npm run release`。

**开发调试**：`npm run tauri dev`（改代码自动热重载/重编译，别每次关掉重开）。

> ⚠️ 别直接双击 `src-tauri\target\debug\writeme.exe`：debug 版设计上要连开发服务器
> `http://localhost:1420`，脱离 `tauri dev` 单独运行会报"无法访问此页面/localhost 拒绝连接"。
> 同理 **普通 `cargo build --release` 编出的 exe 也会连 1420**——独立可用的 exe
> 必须由 `npm run release`（内部走 Tauri CLI `tauri build`）生成。

纯浏览器演示（数据存 localStorage，不进 SQLite）：

```bash
npm run dev           # http://localhost:1420
# 或构建后直接打开 dist/index.html（file://）
npm run build
```

      └─ db.rs             # SQLite 层
